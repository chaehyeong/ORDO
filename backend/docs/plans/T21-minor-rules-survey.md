# 부전공 시행세칙 전수 조사 (2026 교육과정)

2026-11-01 조사. 대상은 `graduation_requirements` 2026학번 중 부전공 총학점이 있는 53개 전공이다. 결과는 V22·V23 과 명세 5장 14번에 반영했다.

## 방법과 한계

- 원본은 `예소/교육과정 책자/국제/2026 교육과정(전체).pdf`. 쪽 번호는 PDF 쪽이다.
- 학과별 부전공 조항, 기본구조표(p121~122), 편성표의 `부전공` 열, 시드 값을 대조했다.
- 편성표 표시는 글자 좌표(열 중심)와 표의 세로선(열 경계) 두 방식으로 세었고, 표시가 있는 19개 전공 모두 결과가 같았다. 코드 없는 행에 찍힌 표시는 없었다.
- 눈으로 확인한 쪽은 13쪽(p167, p266, p315, p377, p402, p587, p611, p634, p657, p845, p885, p985, p1487)이다. 그중 표시가 있는 쪽은 11쪽으로, 표시가 있는 편성표 30쪽의 일부다. 나머지는 위 두 방식과 시드 대조(코드 존재, 지정 필수 학점 합)로 확인했다.
- 2026 교육과정만 봤다. 시드의 2020~2025학번 부전공 학점은 대조하지 않았다.
- 학과 조항의 뜻은 글로 읽은 해석이다. `확인 필요` 항목은 학과에 물어봐야 한다.

## 결론

| 분류 | 전공 수 | 뜻 | 자동 판정에 필요한 것 |
|---|---:|---|---|
| A. 조항·별도 표에서 과목 지정 | 4 | 꼭 들어야 하는 과목이 글이나 표로 정해져 있다 | 과목 목록 입력 |
| B. 편성표에 인정 과목 표시 | 7 | 표시된 과목만 부전공으로 인정되는 것으로 읽힌다 | 표시 과목 목록 입력 |
| C. 편성표에 필수 과목만 표시 | 9 | 표시 과목 학점이 전공필수 요구 학점과 정확히 같다 | 필수 과목 목록 입력 |
| D. 표시가 조항과 맞지 않음 | 2 | 아래 결정대로 판정한다 | 학과 답변 시 수정 |
| E. 과목 지정 없음 | 31 | 그 학과 전공필수·전공선택으로 요구 학점을 채운다 | 지금 데이터로 가능 |

공통으로 기본구조표의 부전공 칸은 전공필수·전공선택뿐이고, 인정 과목을 표시한 학과도 전공기초에는 대부분 표시하지 않았다. 그래서 T21이 전공기초를 후보에서 뺀 것은 대체로 책과 맞지만, 식품생명공학과는 전공기초 통계학·화학1에도 표시했다(p657).

분류 B·C는 편성표 표시를 인정·필수 목록으로 읽은 해석이다. 책에 표시의 뜻을 설명한 문구는 찾지 못했다.

## 책 안에서 내린 결정 (2026-11-01)

발표 전이라 학교 답변을 기다리지 않았다. 책을 한 번 더 확인해 정했고, 답변이 오면 새 마이그레이션으로 고친다.

| 편성표 `부전공` 표시 | 뜻을 설명한 문구를 다시 찾지 못했다(p377 `해당 여부`는 문제해결형 칸이다) | 인정·필수 목록으로 해석한다. C 분류 9개는 표시 학점이 요구 학점과 같다 |
