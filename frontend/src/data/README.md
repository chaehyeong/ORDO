# 배분이수 과목 목록

`distributionCourses.json`은 제공된 **2026 교육과정(전체).pdf**의 국제캠퍼스 교양교육과정 편성표 27~35쪽에서 추출했다. 배분이수 순번 7~343의 337과목이며 모두 3학점이다. 원본 파일의 SHA-256과 과목별 출처 쪽을 JSON에 기록한다.

- 학수번호가 비어 있는 10과목은 `courseCode: null`로 유지한다.
- 원문 표에는 배분이수 영역 번호가 없으므로 번호를 추정하거나 영역 충족 판정에 사용하지 않는다.
- 교육과정에 편성된 과목이며 특정 학기의 실제 개설 목록이 아니다.
- 선택한 과목은 기존 `PUT /api/academic/plans`로 학수번호·과목명·배분이수 분류·학점을 저장한다. 학기별 계획 저장 범위이며 졸업 가능 여부 계산을 추가하지 않는다.

목록을 다시 만들려면 `pypdf`가 있는 Python으로 frontend 폴더에서 실행한다.

```powershell
python .\tools\generate_distribution_courses.py "교육과정 PDF 경로"
```

스크립트는 순번 누락·중복 학수번호·예상과 다른 학점과 과목명 길이를 검사한다. 다른 연도나 문서 구조에 적용하기 전에 페이지 범위와 검증 조건을 갱신해야 한다.
